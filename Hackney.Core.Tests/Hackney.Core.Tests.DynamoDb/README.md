# Hackney.Core.Tests.DynamoDb

This project contains unit tests for the `Hackney.Core.DynamoDb` package. It covers configuring the DynamoDB client for local and AWS modes, the property converters, paged results, the health check, and applying a partial update to an entity.

## Run the tests

From the repository root:

```bash
dotnet test Hackney.Core.Tests/Hackney.Core.Tests.DynamoDb/Hackney.Core.Tests.DynamoDb.csproj
```
